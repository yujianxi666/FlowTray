# FlowTray 产品简报（MVP）

版本：0.1.0 · 2026-10-30
一句话：**电脑上的跨应用文件中转坞。把东西拖进来，稍后拖出去，到期自动清理。**

## 1. 问题

桌面上的临时文件往往卡在三个动作之间：

1. **收集**：从下载目录、聊天窗口、邮件附件、截图里凑齐几份材料。
2. **流转**：切到另一个应用（微信、邮件、浏览器、资源管理器）再用掉。
3. **清理**：任务完成后，桌面/下载文件夹留下一堆"回头再删"的文件。

Windows 的资源管理器、剪贴板、微信收藏各自解决一部分，但没有一个轻量、始终在侧边、既不复制大文件也不上传云端的「临时停靠区」。华为手机上的文件中转站证明了这个心智；桌面端需要同样顺手的本地方案。

## 2. 目标用户

| 用户 | 典型任务 | 痛点 |
| --- | --- | --- |
| 办公室知识工作者 | 把 3 个附件从下载目录拖到邮件/微信 | 反复切换窗口，容易漏附件 |
| 设计/内容创作者 | 收集截图、素材、链接，稍后贴进文档 | 桌面变乱，素材散落 |
| 开发者/运营 | 暂存日志片段、链接、安装包 | 需要跨应用复制，讨厌上传网盘 |
| 经常处理"临时任务"的人 | 白天收集，晚上清理 | 忘记清理，或误删重要文件 |

共同点：**单机、Windows、每天多次、对隐私敏感、不愿意为小任务打开一个重型工具**。

## 3. 核心场景

1. 资源管理器选中 3 个文件 → 拖进 FlowTray → 切到微信/邮箱/浏览器批量拖出或复制。
2. 复制一段文本或截图 → `Ctrl + Shift + D` 存入 → 稍后粘贴。
3. 把常用模板、素材固定，不参与自动清理。
4. 桌面太乱时，把待处理文件先"停靠"进来，处理完清空。
5. 重启电脑后，未过期内容恢复；固定项保持；失效原文件有明确状态。

## 4. 产品原则

1. **本地优先，不做云**：没有账号、没有同步、没有遥测。用户的数据不离开电脑。
2. **引用优先，不复制大文件**：默认只记路径；复制是明确选择，不是默认代价。
3. **临时与固定**：默认 24 小时过期，固定项例外；到期清理可撤销。
4. **拖拽是第一动作**：拖入、拖出、批量拖出都要顺；复制/粘贴是兜底。
5. **轻量但不含糊**：半透明毛玻璃，但文字必须可读；错误必须具体。
6. **Windows 原生心智**：托盘、全局快捷键、资源管理器、文件拖放、管理员边界。

## 5. 范围

### P0（本次交付）

- 托盘常驻、侧边悬浮窗、全局快捷键、边缘唤出、置顶、贴边、可调大小。
- 文件/文件夹/图片/文本/URL 拖入；多选；拖入高亮。
- 列表/网格；卡片信息；搜索；类型/固定/失效筛选。
- 多选、批量复制、复制路径、批量固定、批量删除、批量拖出。
- 拖出到其他应用；复制文本/图片/文件到剪贴板；双击打开/定位。
- 生命周期：1h / 24h / 7d / 永不；固定；到期提醒；容量上限；启动恢复与清理。
- 存储：引用/副本；失效标记；重新定位；存储位置迁移。
- 设置分类；开机启动；管理员启动提示；快捷键录制；隐私排除；一键清除。
- 首次 3 步引导；清空/删除/到期可撤销。
- 具体错误：失效、无权限、磁盘不足、取消/不支持。

### 非目标

- 不做网盘、云同步、账号体系。
- 不做完整文件管理器、文件搜索器、压缩工具。
- 不做聊天/邮件客户端集成 SDK；只依赖系统级拖放与剪贴板。
- 不做移动端、macOS、Linux（架构可扩展，本版不承诺）。
- 不做自动更新、遥测、崩溃上报（发布前需要补）。

### P1（下一个迭代建议）

- 全局「暂存当前窗口/截图」动作。
- 文件夹拖出的可配置策略（junction / 复制 / 提示）。
- 多显示器边缘停靠与位置记忆。
- 导出/导入暂存台（加密备份）。
- 标签、颜色、自定义排序。
- 拖入文件的来源应用真实识别（现在依赖前台进程探测）。
- 自动更新与代码签名。

## 6. 成功指标

MVP 阶段以"可用、可信、无数据事故"为优先级：

| 指标 | 目标 |
| --- | --- |
| 快捷键呼出/隐藏 | < 1 秒（实测 49ms / 2ms） |
| 打开到可操作 | < 1.5 秒 |
| 50 卡片滚动 | 无明显掉帧（实测 112ms 完成滚动布局） |
| 拖入 3 文件到出现卡片 | < 1 秒（不含大文件复制） |
| 清空撤销成功率 | 100%（30 秒窗口内） |
| 数据丢失事故 | 0（引用不改源文件；复制拖出使用安全副本） |
| 本地数据清除 | 一键可完成并可重启 |

## 7. 关键风险

1. **权限边界**：管理员应用（如某些微信/杀软）与普通进程之间拖放被 UIPI 拦截。产品提供管理员重启，但不能消除限制。
2. **跨应用差异**：目标应用可能只接受文件、不接受文件夹；只接受文本、不接受 HTML。需要明确兜底（复制）与人工回归清单。
3. **拖出复制语义**：Electron 不允许指定目标放置效果；采用硬链接/临时副本保证不移动源文件，跨磁盘大文件退化并提示。
4. **剪贴板隐私**：监听必须默认关闭，并提供进程排除；日志不能记录内容。
5. **未签名安装包**：SmartScreen 拦截会影响首次体验；发布前需签名。
6. **Electron 体积/内存**：用开发速度与系统级能力换取体积；对"轻量工具"定位是持续张力。

## 8. 验收映射

| 需求 | 实现/证据 |
| --- | --- |
| 拖入 3 个文件正确显示 | E2E 六类内容 + 原生拖出测试；文件列表渲染验证 |
| 拖到资源管理器/聊天/浏览器 | 原生拖出到 Explorer 实测成功；微信/浏览器见人工清单 |
| 复制文本后粘贴 | E2E 读取系统剪贴板验证 |
| 重启恢复 / 固定项不过期 | E2E 重启持久化；固定项 `expiresAt=null` |
| 快捷键 1 秒内 | 实测隐藏 49ms / 呼出 2ms |
| 50 卡不卡 | 实测加载 233ms、滚动 112ms |
| 清空可撤销 / 失效状态 | E2E 清空撤销；`missing` 状态 + 重新定位 |
| 默认不上传 / 一键清除 | 无网络请求；清除数据入口 + 日志脱敏 |
