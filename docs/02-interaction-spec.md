# FlowTray 交互规范（MVP）

## 1. 信息架构

```
FlowTray 悬浮窗
├─ 暂存台（默认）
│  ├─ 顶栏：品牌 / 计数 / 剪贴板存入 / 设置 / 隐藏
│  ├─ 搜索 + 视图切换 + 类型/固定/失效筛选
│  ├─ 已固定分组 → 卡片
│  ├─ 暂存分组 → 卡片
│  ├─ 底部：容量 / 隐私 / 清空
│  ├─ 多选状态栏
│  ├─ 右键菜单 / 信息详情
│  ├─ 拖入覆盖层
│  └─ 撤销 / 提示 Toast
├─ 设置（全屏覆盖）
│  └─ 通用 / 悬浮窗 / 存储与清理 / 拖拽 / 剪贴板与隐私 / 快捷键 / 关于
└─ 首次引导（全屏覆盖，3 步）
```

### 悬浮窗尺寸

- 默认卡片宽 396px × 高 680px；窗口与卡片等大，不再保留阴影 gutter，避免透明窗口在 DWM 合成时出现黑边（贴左时同样无额外边框）。
- 卡片宽度 340–560px；高度 480–1000px，且不超过工作区高度减 32px。
- 预设：紧凑 360×600 / 标准 396×680 / 宽绰 452×760。
- 拖动左边缘调宽，左下角同时调宽高；设置里也有预设。
- 窗口不进入 Alt+Tab（skipTaskbar）；通过托盘、快捷键、边缘唤出。

## 2. 窗口行为

### 显示

- 快捷键：立即显示并聚焦；渲染层 320ms 带过冲的曲线平移（先向屏内多跑 6px，再回弹到 0），窗口本身先立即出现。
- 托盘左键：显示/隐藏；菜单「显示/隐藏」。
- 边缘唤出：光标在屏幕侧边缘中段（垂直 15%–85%）停留 450ms 后 `showInactive` 出现，不抢焦点；鼠标离开边缘 80px 后重新武装。
- 边缘提示：光标进入屏幕左/右 1/4 宽度时，先在贴边处出现 32×180 的细长提示条（不抢焦点、点击穿透），贴近边缘停留 450ms 后展开完整悬浮窗。提示条垂直跟随光标，离开 1/4 区域后消失。
- 显示时始终贴当前光标所在显示器的侧边；每次显示重新计算位置。
- 始终置顶采用 topmost；显示后调用 `moveTop`，避免被其他置顶窗口压住。

### 隐藏

- 快捷键再按一次 / `Esc`（无浮层、无选择时）/ 顶栏隐藏按钮 / 托盘。
- 先发 `window-will-hide`，CSS 190ms 加速滑出 + 淡出，200ms 后 `hide()`；再次显示会取消待执行隐藏。
- 默认不因失焦隐藏；可开启「失焦自动收起」。拖入/拖出、拖拽调整尺寸期间用 interaction lock 阻止失焦收起。
- 关闭窗口按钮在这个工具里等价于隐藏；退出只能从托盘或设置/关于？——目前仅托盘「退出 FlowTray」与系统退出。

### 边缘唤出细节

- 使用 `screen.getCursorScreenPoint()` 每 150ms 轮询，不安装全局鼠标/键盘钩子，不需要管理员权限。
- 触发后要等光标离开边缘 80px 才再次触发，防止「隐藏后立刻弹出」。
- 与拖拽文件到边缘兼容：光标在边缘停留期间同样会触发，悬浮窗出现后即可作为放置目标。
- 关闭「边缘悬停唤出」后完全不轮询。

## 3. 首次引导（3 步）

| 步骤 | 目标 | 内容 |
| --- | --- | --- |
| 01 唤出 | 建立快捷键心智 | 桌面 + 侧边滑出示意；大号键帽显示当前快捷键；可设置中修改 |
| 02 暂存 | 建立拖入心智 | 文件卡片落入暂存台的示意；列出支持类型；解释引用不复制；可「试试存入当前剪贴板」 |
| 03 流转 | 建立拖出心智 | 卡片 → 微信 / 邮件 / 浏览器 / 资源管理器的示意；隐私承诺；开机启动开关；开始使用 |

- 顶部「跳过」、底部「下一步 / 上一步」；Esc 视为跳过。
- 跳过与完成都会写入 `onboardingDone`，重启不再自动弹出；设置「关于」可重新查看。
- 引导可在没有暂存内容时覆盖整个悬浮窗；不阻塞数据操作（完成前仍可调用 API，但 UI 被覆盖）。

## 4. 暂存台：拖入

### 支持内容

| 类型 | 判定 | 展示 |
| --- | --- | --- |
| 文件 | 普通文件；非图片扩展名 | 扩展名 + 类型图标 |
| 文件夹 | 目录 | 文件夹图标 + 「文件夹」 |
| 图片 | 常见图片扩展名（png/jpg/webp/gif/svg/avif…） | 真实缩略图；失败用类型牌 |
| 文本 | 纯文本/富文本（保留纯文本，可选 HTML） | 名称取首行；卡片显示摘要 |
| 链接 | 单个 http(s) URL | 域名 + 路径；浏览器打开 |

一次最多 200 个路径；文本最大 2,000,000 字符；剪贴板图片最大 64MB；暂存总上限 3000 项。

### 拖入反馈

- 外部拖入经过窗口时：整卡覆盖层出现，虚线酸橙色边框、图标、"松手，放进流转台"、类型 chips。
- 覆盖层下方显示当前模式：「复制暂存 · 按住 Ctrl 临时切换」。按住修饰键移动时实时更新为剪切。
- 拖入时记录来源应用（前台进程探测，最多 300ms），失败则不显示来源。
- 放下后进入处理态：spinner +「正在接收 N 项…」；完成后轻提示「已存入流转台 N 项」，重复项提示「已在暂存台中，已为你置顶」。
- 拖入文件不支持时（例如拖动纯 HTML 无文本、不可读路径）提示具体原因，不默默失败。
- 视觉上不复制大文件时也应立即出现卡片（缩略图异步生成）。

### 拖入复制 / 剪切

- 默认由设置「拖入时」决定：复制 / 剪切；默认复制。
- 按住设置的切换键（默认 Ctrl）反转；例如默认复制时按住 Ctrl = 剪切。
- 剪切语义：把源文件/文件夹移入 FlowTray 的本地副本目录（不是仅记录），并从原位置移除；卡片信息里可「放回原位置」。
- 剪切受保护路径（Windows、Program Files、ProgramData、FlowTray 自身存储、磁盘根）会被拒绝并说明原因。
- 复制语义：按全局「仅引用 / 复制副本」策略落盘；引用不占容量，副本计入容量。
- 剪贴板文件不应用剪切：始终复制/引用，避免误移。

### 重复项

- 身份键：文件路径+大小+mtime（Windows 路径不区分大小写）；文本 SHA-256；URL 归一化；剪贴板图片内容 hash。
- 重复时把已有卡片移到最新、延长未固定项的到期时间、更新来源，不新建卡片。

## 5. 卡片

### 列表卡（默认）

```
[✓] [缩略图/类型牌]  名称（最多一行，搜索命中高亮）        [23h]
                     类型 · 大小 · 来源应用               [固定图钉]
```
- 行高 62px，圆角 11px；悬停出现浅背景 + 浮起操作条（复制 / 固定 / 更多）。
- 左侧 15px 选择圈；选中显示酸橙填充 + 深色勾。
- 右侧到期：≤15 分钟变琥珀色；固定项显示图钉；永久项显示 ∞；失效显示红色「失效」。
- 失效卡片：名称下显示「文件已移动或删除」+「重新定位」；仍可删除、查看信息。
- 固定项在列表顶部独立分组「已固定」；其余为「暂存」。
- 网格卡：缩略图 1.55:1；名称最多两行；底部到期 + 悬停操作；选择圈和固定图钉覆盖在缩略图上。

### 卡片展示的信息

卡片上：类型、缩略图/类型牌、名称、大小（文本为字数，URL 为域名）、来源应用（可关闭）、到期/固定/失效状态、创建顺序。

「查看信息」中补充：完整来源、创建时间、到期时间、存储方式（引用/副本/已移入）、状态、完整路径、原件位置、文本全文、图片尺寸。

### 卡片操作

| 操作 | 入口 | 结果 |
| --- | --- | --- |
| 复制 | 悬停操作 / 右键 / Ctrl+C | 文件→文件列表；文本→文本；图片→PNG；URL→链接+HTML |
| 复制路径 | 右键 / 选中后 Ctrl+Shift+C | 文件/文件夹/图片的绝对路径 |
| 固定 | 图钉 / 右键 | `expiresAt=null`，不自动清理；再次取消恢复从现在起的有效期 |
| 打开 | 双击 / 右键 / Enter | 文件用默认程序，URL 用浏览器，文本打开详情 |
| 定位 | 右键 / 信息 | 资源管理器高亮文件 |
| 重新定位 | 失效状态 | 选新路径，改回引用并重建缩略图 |
| 放回原位置 | 右键 / 信息（仅剪切移入） | 把本地副本移回原位；原位置存在冲突则拒绝 |
| 删除 | 右键 / Delete | 软删除，10 秒内可撤销 |
| 查看信息 | 右键 | 详情页 |

## 6. 多选与批量

- 单击：选中该卡（已多选时收拢为单卡）；再次单击已选单卡不取消。
- Ctrl/⌘ + 单击：切换选中。
- Shift + 单击：按当前可见顺序范围选择。
- 选择圈点击：切换；Shift 范围。
- 全选：Ctrl+A，选择当前搜索/筛选下的可见卡片；不选隐藏项。
- 底部选择栏：`已选 N 项`、拖动提示、复制、路径、固定/取消固定、删除、取消选择。
- 删除与清空可撤销；批量固定一次事务写入。
- 批量拖出：拖动任意已选卡片，拖出所有已选的**文件类**卡片；混合选择中的文本/链接不参与原生文件拖拽（需单独拖/复制）。卡片左上提示会说明。

## 7. 搜索与筛选

- 搜索：名称、文本全文、URL、来源、路径、扩展名；空格分词，全部命中；大小写不敏感；输入即时过滤。
- 快捷键 `/` 或 `Ctrl+F` 聚焦；空输入时 `/` 提示；Esc 清空/失焦。
- 类型 chips：全部 / 文件（含文件夹）/ 图片 / 文本 / 链接，各带计数。
- 固定 chip：只看固定；失效 chip：只在有失效项时出现。
- 修改搜索/筛选会清空选择，避免隐藏项被误删。
- 空状态区分「完全为空」与「筛选无结果」，后者一键清除筛选。

## 8. 拖出

- 文件/文件夹/图片：调用 Electron `webContents.startDrag`，多文件通过 `files[]` 一次拖出。
- 拖出前生成 2× 拖拽图标：深色圆角、酸橙数字块、「N 项 / 复制拖出」；Windows 光标由系统目标反馈。
- 拖出时卡片变暗、显示顶部/底部提示；主进程同步阻塞在拖动循环，结束后通过事件清除状态。
- **复制**：暂存区使用硬链接（文件，同卷）或 NTFS junction（文件夹）作为拖出源；硬链接失败且 ≤64MB 时复制；否则退化为原路径并提示。目标应用移动/删除暂存内容不会影响原文件。
- **剪切**：直接拖源路径；拖动结束后 0.9 秒检查路径是否消失，消失则从暂存台移除。
- 文本卡片：使用 HTML5 原生文本拖拽（`text/plain`，URL 额外带 `text/uri-list`），可直接拖到记事本/聊天输入框。
- 拖到不支持的应用/位置：系统不显示可放置状态；FlowTray 不谎报成功；仍可通过「复制」兜底。
- 拖出目标应用如果是管理员进程，普通 FlowTray 会被 Windows 阻止；使用管理员重启。

## 9. 生命周期与撤销

- 新内容写 `expiresAt = now + 默认有效期`；固定项写 null。
- 未固定项到期：状态 `expired`，从视图消失；Toast「到期清理 N 项，可在 60 秒内撤销」；固定项永不过期。
- 启动时：恢复数据库 → 校验文件存在 → 清理过期 → 清理 7 天前的软删除/过期内容。
- 运行中每 30 秒扫描到期；每 3 分钟校验文件是否被移动/删除；每小时清理回收站与临时拖拽缓存。
- 失效：文件不存在但未到期 → `missing`，卡片保留并提示重新定位；不自动删除。
- 容量：仅统计 FlowTray 自有的文件副本与缩略图；超过上限拒绝新副本，但引用仍可加入。
- 清空默认只清未固定项；对话框提供「同时移除已固定内容」开关；30 秒撤销恢复全部。
- 删除 10 秒撤销；到期 60 秒撤销（恢复时延长有效期）。新的删除/清空/到期操作会替换上一个撤销状态。

| 分类 | 项目 |
| --- | --- |
| 通用 | 主题、**深色/浅色主题配色（背景色 + 强调色）**、开机自动启动、管理员自启动、启动时展开、停靠左/右、边缘悬停唤出、触发延迟、失焦自动收起 |

| 拖拽 | 拖入默认复制/剪切、拖出默认复制/剪切、临时切换键 Ctrl/Shift/Alt、安全复制拖出、当前行为示例 |
| 剪贴板与隐私 | 自动监听（默认关）、剪贴板上限、敏感应用 chips、恢复默认排除列表、日志脱敏说明、数据/日志目录、清除暂存数据、重置全部本地数据 |
| 快捷键 | 呼出/隐藏录制、剪贴板存入录制、冲突提示、恢复默认 |
| 关于 | 版本/Electron、三条本地优先原则、数据路径、重新引导、恢复默认设置 |

- 所有设置即时保存，无「保存」按钮；顶部显示「改动即时保存 / 保存中 / 已自动保存」。
- 快捷键录制：点击后暂停全局快捷键；按下组合键；Esc 取消。要求至少一个 Ctrl/Alt/Shift + 字母/数字/F1–F24/方向键等；Esc 外不支持单一 Win 键。冲突时保留旧值并提示。
- 存储位置迁移：原生目录选择 → 校验空目录/写入权限 → 迁移 `files` 与 `thumbs` → 失败回滚；迁移中全屏遮罩。
- 管理员设置：非管理员时开关禁用并给出「以管理员身份重启」；管理员自启动通过计划任务。
- 危险操作：清空/重置都需确认对话框，重置明确 "不可撤销"。

## 11. 错误提示（文案与动作）

| 场景 | 文案 | 动作 |
| --- | --- | --- |
| 文件失效 | 「文件已移动或删除」 | 重新定位 / 删除 |
| 无权限 | 「没有权限读取或写入「xxx」。请检查文件权限，或以管理员身份运行 FlowTray。」 | 管理员重启 |
| 磁盘不足 | 「磁盘空间不足，无法写入「xxx」。至少还需要 X 可用空间。」 | 清理 / 更换存储位置 |
| 超出容量 | 「容量不足：还需要 X，当前上限 Y。」 | 调整上限 / 清理 |
| 不支持 | 「暂不支持这种内容。支持文件、文件夹、图片、文本与链接。」 | 关闭 |
| 重复 | 「已在暂存台中，已为你置顶」 | 定位已有卡片 |
| 敏感应用 | 「当前应用「xxx」在隐私排除列表中，未收录剪贴板内容。」 | 设置里编辑排除列表 |
| 快捷键冲突 | 「“呼出/隐藏”快捷键 X 注册失败，可能被其他应用占用。」 | 去快捷键设置 |

Toast 出现在底部，成功后自动消失；错误 6 秒；撤销条一直保留到窗口结束或点击关闭。

## 13. 视觉系统

- **气质**：精密仪器 + 温暖纸感；深墨绿玻璃与酸橙信号，不用常见的紫色 AI 渐变。
- **深色**：默认黑 `#000000` + 白 `#FFFFFF`；背景、强调色均可在设置里改。
- **浅色**：默认白 `#FFFFFF` + 灰 `#808080`；与深色独立保存。
- **固定语义色**：固定琥珀、错误珊瑚红、文件类型色保持可辨识；强调色只作用于按钮、选中态、品牌标记和提示条。
- **字体**：Segoe UI Variable / 微软雅黑 UI 系统栈；数字使用 tabular-nums；无网络字体。
- **文字**：根据背景亮度自动选深色/浅色文字，避免自定义背景后不可读；极端撞色仍可能影响类型徽标。
- **形状**：左侧大圆角 28px（更向内收）、贴边侧直角；卡片 11–13px；键帽 6px。
- **层级**：半透明底 84–98%（仅 CSS 透明，不使用系统 acrylic；避免窗口矩形底材露出黑边）；1px 内描边；无外部 gutter；噪点 2.6%。
- **动效**：140–220ms，`cubic-bezier(.16,1,.3,1)`；卡片入场最多延迟 70ms；尊重系统 reduced motion 与设置项。
- **可读性**：正文最小 10px、设置辅助 9.2px、主要名称 12.5px；暗色正文对比度优先于透明度。
- **等待态**：spinner；禁止骨架屏闪烁；长操作显示明确文案。

## 14. 可访问性

- 所有交互元素有 aria-label / title；开关 role=switch，分段 role=radio，菜单 role=menu。
- 焦点可见（2px 酸橙 outline）；卡片可 Tab 聚焦并操作。
- 颜色不是唯一状态：固定有图钉 + 文案；失效有图标 + 文案；到期有文字。
- Toast `aria-live=polite`；菜单支持方向键、Home/End、Esc。
- 减少动态：系统 prefers-reduced-motion + 设置开关。

## 15. 空状态与首次使用

- 无内容：大号托盘插画 +「把要用的东西，先停靠在这里」+ 拖入/快捷键说明 + 从剪贴板暂存 + 怎么用 + 隐私承诺。
- 搜索无结果：SearchX + 关键词 + 清除筛选。
- 只筛选到空：说明当前筛选条件。
- 权限/日志/备份操作都在设置内，不污染主界面。
